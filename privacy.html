Privacy policy

Byron Gmail. Last updated 30 October 2026.

Who this applies to

Byron Gmail is a personal tool used only by its developer, Byron Bunning, with his own Google accounts. It is not offered to anyone else.

What Google user data it accesses

The app requests one permission: read-only access to Gmail (gmail.readonly). With it, the app can read email messages, threads, headers and attachment names. It cannot send, delete or modify email, and it does not access Google Drive, Calendar, Contacts or any other Google service. It also reads the account's email address so each result can be labelled with the account it came from.

How the data is used

Email is fetched only when the user asks their AI assistant (Claude, by Anthropic) to search or read email. The requested results are passed to that assistant so it can answer the user's request. Nothing is fetched in the background, and email is not used for advertising, profiling or any other purpose.

Storage

  • OAuth refresh tokens are stored in the macOS Keychain on the user's own computer.
  • A local file lists which account aliases are connected (for example "personal"), with no passwords or tokens in it.
  • The app itself does not save email content to disk or to any server.

Sharing

Google user data is not sold or shared with anyone. The only party that receives email content is Anthropic, and only the specific emails the user asks Claude to read, as part of the user's own conversation. Anthropic's handling of that content is covered by Anthropic's privacy policy.

Limited use

Byron Gmail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Running the app's remove command also deletes the stored token from the keychain.
